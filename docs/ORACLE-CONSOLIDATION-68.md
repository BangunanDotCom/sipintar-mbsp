## Makmal dan serahan JTIK

- Pasang versi 001–005 melalui `scripts/oracle/install.ts`. Semak manifest sebelum seed. 004 mengekalkan checksum 001–003 dan menambah `STL_TRAINING_REMINDER_OUTBOX` serta `STL_SYNTH_FINANCIAL_ENTRIES`. Pemulihan snapshot pra-004 bermula dengan skema versi asal. Jadual baharu berada selepas jadual induk dalam eksport. 005 menambah indeks audit berawalan STL_ tanpa DDL jadual.
- Tetapkan `ORACLE_LAB_TRAINING_WORKER_USER` semasa seed kepada pengguna makmal berasingan daripada owner, API dan pengimbas. API boleh memasukkan dan membaca baris outbox; worker mengemas kini lajur penghantaran sahaja. Jurnal kewangan hanya membenarkan bacaan dan append oleh API. Oracle menambah indeks LOB dalaman untuk `STL_LOB_TR_CONTEXT`. Keseluruhan 15 `SYS_IL` yang dipadankan dengan jadual/segmen STL_ ialah cadangan pengecualian, tertakluk pada persetujuan JTIK.
- Jalankan `node --env-file="$ORACLE_LAB_WORKER_ENV" --import tsx scripts/oracle/training-reminders.ts` dengan `NODE_ENV=test`, `STAYLINK_ORACLE_LAB_SYNTHETIC=true`, `STAYLINK_SYNTHETIC_REMINDERS=true`, polisi semakan latihan dan Mailpit pada `127.0.0.1:1025`. Untuk peringatan teknikal, aktifkan completion dan gunakan pelantikan sintetik sepadan.
- Bukti ini terhad kepada Oracle Free 23.26.4. Oracle 19.30 SE2, PDB dan INDECS rasmi memerlukan kelulusan JTIK, semakan grants, prestasi, pemulihan fizikal dan cutover. ### Keputusan gerbang makmal

- Regresi Vitest mencatat 506 lulus, 8 dilangkau dan tiada kegagalan. Dua kes eksklusif Oracle dilangkau pada varian PostgreSQL. Empat perjalanan Completion dan kes Issue #24 memerlukan DB khusus dan masing-masing lulus dalam larian berasingan. Suite asal Team 1 yang memerlukan kit 11 akaun tidak dijalankan. Pengganti untuk perbandingan dua enjin menggunakan fixture sintetik yang sama melalui suite parity.
- TypeScript, lint, binaan dan GitHub Branch Checks lulus. `npm audit` melaporkan 0 kerentanan. Binaan masih melaporkan amaran chunk besar. CI menjalankan gerbang kod, manakala bukti DB dan pelayar datang daripada makmal. [Larian CI kod](https://github.com/BangunanDotCom/sipintar-mbsp/actions/runs/45923398824)
- Playwright Completion lulus 8 kes pada PostgreSQL melalui HTTPS loopback dan 8 kes pada Oracle Free melalui HTTP loopback. Ia meliputi log masuk pemohon, MFA, enam pelantikan pegawai termasuk PIC luar daerah, surat, penapisan PPSK, lejar dan kawalan rekod. Penulisan BKT, KP, keputusan dan bayaran sintetik dilaksanakan dalam empat perjalanan API. Pelayar memeriksa keadaan yang diterbitkan selepas perjalanan itu, termasuk BKT, ulasan dua jabatan, snapshot KP dan keputusan campuran. Ujian fokus PPSK bagi semakan tambahan turut lulus pada setiap enjin. Ujian PDF persendirian, dua syarikat dan jemputan wakil lulus pada setiap enjin.
