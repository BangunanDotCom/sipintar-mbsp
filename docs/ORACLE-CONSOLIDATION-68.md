## Makmal dan serahan JTIK

- Pasang versi 001–004 melalui `scripts/oracle/install.ts`. Semak manifest sebelum seed. 004 mengekalkan checksum 001–003 dan menambah `STL_TRAINING_REMINDER_OUTBOX` serta `STL_SYNTH_FINANCIAL_ENTRIES`. Pemulihan snapshot pra-004 bermula dengan skema versi asal. Jadual baharu berada selepas jadual induk dalam eksport.
- Tetapkan `ORACLE_LAB_TRAINING_WORKER_USER` semasa seed kepada pengguna makmal berasingan daripada owner, API dan pengimbas. API boleh memasukkan dan membaca baris outbox; worker mengemas kini lajur penghantaran sahaja. Jurnal kewangan hanya membenarkan bacaan dan append oleh API. Oracle menambah indeks LOB dalaman untuk `STL_LOB_TR_CONTEXT`. Keseluruhan 15 `SYS_IL` yang dipadankan dengan jadual/segmen STL_ ialah cadangan pengecualian, tertakluk pada persetujuan JTIK.
- Jalankan `node --env-file="$ORACLE_LAB_WORKER_ENV" --import tsx scripts/oracle/training-reminders.ts` dengan `NODE_ENV=test`, `STAYLINK_ORACLE_LAB_SYNTHETIC=true`, `STAYLINK_SYNTHETIC_REMINDERS=true`, polisi semakan latihan dan Mailpit pada `127.0.0.1:1025`. Untuk peringatan teknikal, aktifkan completion dan gunakan pelantikan sintetik sepadan.
- Bukti ini terhad kepada Oracle Free 23.26.4. Oracle 19.30 SE2, PDB dan INDECS rasmi memerlukan kelulusan JTIK, semakan grants, prestasi, pemulihan fizikal dan cutover.
