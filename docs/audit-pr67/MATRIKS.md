# Matriks kebolehkesanan Fasa 1

Matriks ini merakam baseline PR #67. [Matriks K01–K11 pada PR #69](SEMAKAN-PR69.md#matriks-k01k11-dan-proses-lanjutan).

**Status.** **Diuji** = fungsi asas pada baseline disokong oleh ujian yang lulus untuk subskop disebut. **Separa** = sebahagian tingkah laku wujud atau bukti belum meliputi keseluruhan keperluan. **Simulasi** = hasil latihan dengan fixture atau mock. **Belum** = pelaksanaan pada baseline tiada. **Tersekat** = aktivasi atau pengesahan rasmi bergantung pada kelulusan, integrasi atau persekitaran. Lajur jurang merujuk ID penemuan dan ID ujian cadangan. Rujukan hasil sebenar berada dalam [Bukti ujian](BUKTI-UJIAN.md).

## Tafsiran apabila rujukan berbeza

| Perkara | Bukti dan tafsiran |
|---|---|
| Peranan menjana nombor rasmi | `PHASE2.md` menggambarkan nombor selepas pengesahan lengkap PIC. Spesifikasi K08/K10 mengasingkan pengesahan lengkap daripada kuasa pendaftaran dan meninggalkan pelaku rasmi kepada SOP. PR #67 menggunakan PPSK latihan. CR01 memerlukan keputusan rasmi bernama sebelum menerima polisi siri dan kuasa. |
| Rujukan teknikal | Reka bentuk proses lama menyebut selepas pengesahan bayaran sebenar. Issue #68 menggunakan bayaran mock pertama untuk pembangunan sintetik. Ujian sandbox dan operasi mesti membuktikan gerbang masing-masing. |
| Akses kepada draf orang lain | Gerbang ujian awal Fasa 2B menyebut 403. API baseline dan spesifikasi K02 menggunakan 404 untuk menyembunyikan draf luar pemilikan; 403 kekal untuk tindakan terlarang apabila konteks dapat didedahkan. Semak OpenAPI dan asersi penerimaan mengikut kontrak semasa. |
| Penyimpanan maklumat majikan | Follow-up reka bentuk K11 membenarkan pecahan pilihan; keputusan operasi menetapkan angka pekerja untuk Jabatan Bangunan. Jangan jadikan data majikan syarat serahan. Klasifikasi dan penggunaan maklumat tambahan menunggu keputusan pemilik. |
| Kes ditutup | Pelan asal menutup apabila semua skop muktamad dan dokumen dikeluarkan. Issue #68 turut menuntut prasyarat bayaran kedua dan rekonsiliasi. Pelan E14/E15 meliputi kedua-duanya dan memerlukan SOP kelulusan. |
