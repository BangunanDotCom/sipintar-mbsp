# Penemuan dan tindakan penyelarasan

**P0** menyekat kelulusan Go Live. **P1** perlu diselesaikan atau dibuktikan mengikut gerbang Complete Release. **P2** memperkemas kontrak dan bukti. Tahap risiko menilai kesan kepada proses rasmi jika laluan terlibat tersedia. Penemuan bertanda statik berpunca daripada semakan kod. Pengesahan regresi hendaklah dibuat secara defensif pada fixture terasing.

## Kawalan dan skop jaminan

| Kawalan | Bukti baseline | Risiko baki dan kriteria |
|---|---|---|
| Authentication | Argon2, aktivasi e-mel, ID disulitkan dan HMAC unik, kuki HttpOnly/SameSite Strict; Secure pada produksi/hos demo. Sesi tamat dan akaun tidak aktif ditolak. | Polisi idle timeout, revokasi semua laluan sensitif, rate-limit per replika, pemulihan tanpa kebocoran kewujudan akaun. S01/O01 |
| MFA | TOTP dan kod pemulihan, pegawai tanpa MFA disekat, reset berasingan, ujian ulangan TOTP dan pembatalan sesi dalam liputan baseline. | Uji jam MC/UTC, pemulihan terjejas selepas failover, revokasi, privilege dan operator kecemasan. |
| RBAC dan pengasingan daerah | Satu peranan aktif dengan pelantikan sah, semakan permission, skop daerah fixture, tiada verifikasi sendiri, PIC terhad tidak dapat akses dokumen profil global. PPSK/ICT mempunyai kuasa berbeza. | F-02/F-03/F-05/F-10. Bentangkan matriks resource/action lengkap untuk tiga daerah dan tugas rasmi. |
| CSRF | Token berikat sesi, Origin tepat pada mutasi bersesi, kuki Strict, tidak memutar token antara dua tab. Callback mock menggunakan pengesahan HMAC berasingan. | Uji rentas tab, revokasi, dan hasil perantara proksi untuk setiap kumpulan mutasi. |
| XSS dan kandungan | Semakan sumber langsung menjumpai output teks React dan HTML atribusi peta statik. CSP, nosniff dan attachment meliputi bahagian tertentu. | Tiada pengesahan fluens menyeluruh. Uji data tak dipercayai sebagai teks pada UI, audit, eksport, metadata, notifikasi dan penjana surat. Semak CSP sasaran. S03 |
| IDOR | Pemilikan draf dan kuasa semasa ditapis; FK unit/floor/doc dan skop snapshot menjaga bateri silang draf; pegawai mengikut daerah. | Dapatan laluan PDF lama F-03. Ujian grid dalam S02 meliputi list/detail/action/download dan pertukaran peranan. |
| Dokumen | Worker lease dan integriti, status gagal tertutup, storan berversi dan metadata tanpa kunci tersedia untuk komponen dokumen kes. | Aliran fail kes sebenar belum tersedia. Dokumen delegasi mewarisi jurang F-01/F-02. |
| Audit, transaksi dan pendua | Tuntutan jemputan atomik, versi optimistik draf, serahan immutable dengan uniqueness, lock per serahan, transaksi review/notifikasi, invoice/callback deduplikasi. | Regresi kes deadlock, retry selepas commit tidak pasti, pinggir had/expiry dan gangguan silang worker; audit tahan ubah, outbox dan bukti payout. F-05/F-06/F-08 |

Unit Rekod meluluskan pengkelasan, retensi, legal hold dan pelupusan bersama JTIK. JTK mengesahkan sempadan kapasiti dan penggunaan data majikan. Perancang dan Kejuruteraan mengesahkan beban/dasbor jabatan, ulasan serta mekanisme hari ketujuh. BKT dan JK mengesahkan kawalan serahan KP dan keputusan. Status setiap cadangan masih perlu disahkan oleh pemilik dalam daftar keputusan. [Owner Decision Pack](../ict-handover/OWNER-DECISION-PACK.md)
